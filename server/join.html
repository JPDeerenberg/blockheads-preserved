The Blockheads Preserved

Point the game at your own server. No account, no store, no cloud.

  1. Open Join World → Advanced… → Online IP/Port
  2. Enter your server address and 15151
blockheads://join.php?ip=…
Open in game

Automatic link opening depends on Android intent delivery and has not been verified on every version. If nothing happens, use the Online IP/Port dialog above — that always works.

Running the server: docker compose up -d in the server/ folder. See the project README for internet hosting and passwords.
